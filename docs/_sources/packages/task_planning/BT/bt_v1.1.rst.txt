Controle Customizado
--------------------

ParallelAny
^^^^^^^^^^^
* **Tipo:** Control Node
* **Natureza:** Síncrono

Diferente do nó `Parallel` padrão (que aguarda N sucessos ou N falhas), este nó implementa uma lógica de "curto-circuito" (OR lógico em paralelo).

* **Comportamento:**
    1. Executa **todos** os nós filhos simultaneamente a cada *tick*.
    2. Retorna **SUCCESS** imediatamente se *qualquer* filho retornar `SUCCESS`.
    3. Retorna **FAILURE** imediatamente se *qualquer* filho retornar `FAILURE`.
    4. Retorna **RUNNING** caso contrário.

* **Aplicação Principal:**
    Implementação de **condições de guarda** em paralelo.
    *Exemplo:* "Seguir Caminho" EM PARALELO COM "Monitorar Sensor de Queda". Se o sensor indicar queda (FAILURE), a navegação é abortada imediatamente.

Condições (Conditions)
----------------------

IsReachable
^^^^^^^^^^^
* **Tipo:** Condition Node
* **Natureza:** Síncrono (Cálculo Geométrico / Cinemática)

Substitui o antigo *IsRobotNear*. Verifica se a pose de manipulação (Pick ou Place) é alcançável pelo robô na posição atual. Se não for, calcula uma posição de base válida para navegação.

* **Portas de Entrada (Input):**
    * ``target`` (Pose): A pose 3D do objeto ou local de deposição desejado.
    * ``object_id`` (string): Identificador do objeto (usado para contexto de colisão ou logs).
    * ``robot_base_z`` (double): Altura da base do robô (offset Z) em relação ao solo.
    * ``max_reach_3d`` (double): Raio máximo absoluto de alcance do braço (esfera de alcance) para pré-filtro.
* **Portas de Saída (Output):**
    * ``adjustment_pose`` (Pose): Chave da Blackboard onde a nova pose de navegação será escrita caso o alvo não esteja alcançável.
* **Lógica:**
    1. **Pré-filtro:** Verifica se a distância euclidiana até o ``target`` é menor que ``max_reach_3d``.
    2. **Validação IK:** Se estiver no raio, tenta resolver a Cinemática Inversa para garantir que o braço alcança a pose sem colisão.
    3. **Resultado:**
        * **SUCCESS:** O alvo é alcançável da posição atual (a árvore pode prosseguir para o *Pick/Place*).
        * **FAILURE:** O alvo não é alcançável. O nó calcula uma nova posição de base (projetada no plano XY ao redor do alvo) e escreve na porta ``adjustment_pose`` para que a árvore acione a navegação (via *FollowPath*).

IsGripperHoldingObject
^^^^^^^^^^^^^^^^^^^^^^
* **Tipo:** Condition Node
* **Natureza:** Síncrono (Leitura de Memória)

Verifica o estado físico do efetuador final (garra) para garantir que o objeto ainda está seguro.

* **Lógica:**
    Consulta o nó de monitoramento da garra via ponteiro compartilhado.
    * **SUCCESS:** Se o sensor indicar pressão/contato.
    * **FAILURE:** Se a garra estiver vazia.
    * **Efeito Colateral:** Pode acionar paradas de emergência se o objeto cair durante o transporte.

IsPathClear
^^^^^^^^^^^
* **Tipo:** Condition Node
* **Natureza:** Síncrono (Tick-based Check)

Verifica continuamente se o caminho planejado permanece livre de obstáculos dinâmicos (ex: pessoas ou objetos que entraram na cena após o planejamento inicial).

* **Portas de Entrada (Input):**
    * ``path`` (Path): O caminho global gerado anteriormente pelo ``ComputePath``.
* **Lógica:**
    Itera sobre os pontos da trajetória futura e verifica sua validade contra o *Costmap* local ou global atualizado.
    * **SUCCESS:** O caminho está livre.
    * **FAILURE:** Um obstáculo foi detectado na rota (deve acionar replanejamento).
* **Uso:** Normalmente inserido em uma `ReactiveSequence` junto com o nó `FollowPath`.

Percepção e Contexto
--------------------

DetectObject
^^^^^^^^^^^^
* **Tipo:** Action Node (Simple)
* **Natureza:** Síncrono

Gerencia a triagem e seleção de alvos a partir do fluxo de dados do sistema de visão computacional.

* **Portas de Saída (Output):**
    * ``output_pose`` (Pose): Posição espacial do objeto selecionado.
    * ``output_id`` (string): Identificador único do objeto.
    * ``object_size`` (Vector3): Dimensões da Bounding Box.
* **Lógica (Latch):**
    1. **Modo Rastreamento:** Se já existe um alvo ativo, retorna seus dados atuais (**SUCCESS**).
    2. **Modo Busca:** Se não há alvo, verifica a fila de novas detecções aplicando filtros.
    3. Se um novo objeto válido for encontrado, ele é promovido a alvo atual.

ComputePath
^^^^^^^^^^^
* **Tipo:** Action Node (Async)
* **Natureza:** Assíncrono (Action Client)

Solicita o cálculo de uma rota livre de obstáculos ao planejador global.

* **Portas de Entrada (Input):**
    * ``target`` (Pose): O destino final desejado.
    * ``planner`` (string): ID do algoritmo de planejamento.
* **Portas de Saída (Output):**
    * ``path`` (Path): A trajetória calculada, salva na Blackboard para ser consumida por ``FollowPath`` e ``IsPathClear``.
* **Comportamento:**
    * **SUCCESS:** Caminho válido calculado e armazenado.
    * **FAILURE:** Destino inalcançável.

FollowPath
^^^^^^^^^^
* **Tipo:** Action Node (Async)
* **Natureza:** Assíncrono (Action Client)

Substitui o antigo *NavigateTo*. É responsável exclusivamente pela execução da trajetória (Controller Server) em malha fechada.

* **Pré-requisito:** Deve receber um caminho válido gerado por ``ComputePath``.
* **Portas de Entrada (Input):**
    * ``path`` (Path): O caminho a ser seguido.
    * ``controller_id`` (string): ID do controlador (ex: "FollowPath").
* **Comportamento:**
    Envia o caminho para o Action Server do Controlador.
    * **RUNNING:** Enquanto o robô segue a linha da trajetória.
    * **SUCCESS:** Quando a tolerância do objetivo final é atingida.
    * **FAILURE:** Se o desvio for muito grande ou o controlador falhar.
