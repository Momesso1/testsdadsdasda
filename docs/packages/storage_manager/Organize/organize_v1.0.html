organize.cpp (Atual v1.0 - Composable Node)

O OrganizeNode é responsável pela inteligência geométrica de armazenamento. Ele não move o robô fisicamente, mas calcula as coordenadas exatas onde o robô deve colocar um objeto para otimizar o espaço dentro de uma caixa ou prateleira.

Arquitetura de Composição

Este nó é implementado como um Composable Node (rclcpp_components). Em vez de se comunicar via tópicos ou serviços (que adicionariam latência e complexidade de serialização), ele é instanciado dentro do mesmo processo do ServerNode.

Isso permite que o ServerNode chame o método placeObjectInBox diretamente, como se fosse uma função de biblioteca, garantindo performance máxima para o cálculo matemático.

// Construtor: Inicializa o nó como um Componente.
// Este nó é projetado para ser carregado pelo 'ServerNode' via composição,
// permitindo chamadas diretas de função sem latência de tópicos.
OrganizeNode::OrganizeNode(const rclcpp::NodeOptions & options)
: Node("organize_node", options)
{
    RCLCPP_INFO(this->get_logger(), "Organize Node iniciado (Lógica de Bin Packing).");
}

Lógica de Empacotamento (Bin Packing)

O método principal, placeObjectInBox, implementa um algoritmo de preenchimento de grade 3D (Grid Filling).

Funcionamento: 1. Grade Virtual: Divide o volume da caixa de armazenamento em células baseadas no tamanho do objeto + margem de segurança (padding). 2. Cálculo Relativo: Determina a posição \((x, y, z)\) relativa ao canto inferior esquerdo da caixa baseada nos índices atuais \((i, j, k)\). 3. Transformação Espacial: Aplica a rotação da caixa (Quaternion) para transformar a coordenada relativa em uma Pose Global no mundo. 4. Atualização de Índices: Calcula qual será a próxima vaga livre, preenchendo primeiro o eixo X, depois Y, e por fim empilhando em Z.

Implementação Detalhada:

  1// Algoritmo de Bin Packing (Empacotamento)
  2// Calcula a posição exata (Pose) onde um objeto deve ser colocado dentro de uma caixa/prateleira,
  3// baseando-se em uma grade 3D virtual.
  4std::pair<geometry_msgs::msg::Pose, std::vector<int>> OrganizeNode::placeObjectInBox(
  5    const geometry_msgs::msg::Pose &storage_pose,    // Pose central da caixa de armazenamento
  6    const geometry_msgs::msg::Vector3 &storage_size, // Tamanho total da caixa (L, A, P)
  7    const geometry_msgs::msg::Vector3 &object_size,  // Tamanho do objeto a ser guardado
  8    const float object_padding,                      // Espaço extra entre objetos
  9    const float z_lift_offset,                       // Altura para levantar ao colocar (evitar colisão com a borda)
 10    int idx_x, int idx_y, int idx_z)                 // Índices atuais da grade (coluna, linha, camada)
 11{
 12    // 1. Definição da Célula da Grade
 13    // O tamanho ocupado por cada objeto é seu tamanho físico + margem de segurança (padding)
 14    double cell_x = object_size.x + object_padding;
 15    double cell_y = object_size.y + object_padding;
 16
 17    // Validação de segurança para evitar divisão por zero ou lógica inválida
 18    if (cell_x <= 0 || cell_y <= 0 || object_size.z <= 0) 
 19    {
 20         RCLCPP_ERROR(rclcpp::get_logger("organize_node"), "Dimensões inválidas detectadas.");
 21         geometry_msgs::msg::Pose failed_pose;
 22         return std::make_pair(failed_pose, std::vector<int>{-1, -1, -1});
 23    }
 24
 25    // 2. Cálculo de Capacidade Máxima
 26    // Quantos objetos cabem em cada eixo (X, Y, Z) dentro do Storage
 27    int max_idx_x = std::floor(storage_size.x / cell_x);
 28    int max_idx_y = std::floor(storage_size.y / cell_y);
 29    
 30    int raw_max_z = std::floor(storage_size.z / object_size.z);
 31    int max_idx_z = (raw_max_z == 0) ? 1 : raw_max_z; // Garante pelo menos 1 camada
 32    
 33    // Verifica se os índices solicitados estouram a capacidade da caixa
 34    bool z_overflow = (idx_z >= max_idx_z);
 35
 36    // Permite colocar objetos maiores que a caixa no eixo Z se for a primeira camada (ex: em cima de uma mesa)
 37    if (storage_size.z < object_size.z && idx_z == 0) 
 38    {
 39        z_overflow = false; 
 40    }
 41
 42    if (idx_x >= max_idx_x || idx_y >= max_idx_y || z_overflow)
 43    {
 44        RCLCPP_WARN(rclcpp::get_logger("organize_node"), 
 45                    "Storage Cheio! Índices [%d, %d, %d] excedem limite [%d, %d, %d].",
 46                    idx_x, idx_y, idx_z, max_idx_x, max_idx_y, max_idx_z);
 47        
 48        geometry_msgs::msg::Pose failed_pose;
 49        return std::make_pair(failed_pose, std::vector<int>{-1, -1, -1});
 50    }
 51
 52    // 3. Cálculo da Origem Relativa (Canto Inferior Esquerdo)
 53    // O ROS usa o centro do objeto como (0,0,0). Para criar uma grade, precisamos
 54    // começar do canto da caixa.
 55    // Start X = -Metade_Caixa + Metade_Objeto (para centralizar o primeiro objeto na célula)
 56    double start_x = - (storage_size.x / 2.0) + (cell_x / 2.0);
 57    double start_y = - (storage_size.y / 2.0) + (cell_y / 2.0);
 58    
 59    // No Z, assumimos que storage_pose.z é o centro da caixa ou a base. 
 60    // Ajustamos para garantir que o objeto fique apoiado.
 61    double start_z = (object_size.z / 2.0) + z_lift_offset;
 62
 63    // 4. Cálculo da Posição Relativa
 64    // Posição = Origem + (Índice * Tamanho da Célula)
 65    double pos_x_rel = start_x + (idx_x * cell_x);
 66    double pos_y_rel = start_y + (idx_y * cell_y);
 67    double pos_z_rel = start_z + (idx_z * object_size.z); 
 68
 69    // 5. Transformação de Coordenadas (Rotação)
 70    // Se a caixa estiver rotacionada no mundo, a grade interna também deve rotacionar.
 71    geometry_msgs::msg::Pose final_pose;
 72    
 73    // Recupera a orientação da caixa (Quaternion)
 74    tf2::Quaternion q_storage(
 75        storage_pose.orientation.x, 
 76        storage_pose.orientation.y, 
 77        storage_pose.orientation.z, 
 78        storage_pose.orientation.w
 79    );
 80    
 81    // Aplica a rotação da caixa ao vetor de posição relativa calculado acima
 82    tf2::Matrix3x3 m_storage(q_storage);
 83    tf2::Vector3 vec_rel(pos_x_rel, pos_y_rel, pos_z_rel);
 84    tf2::Vector3 vec_world = m_storage * vec_rel; 
 85    
 86    // Soma o vetor rotacionado à posição central da caixa no mundo
 87    final_pose.position.x = storage_pose.position.x + vec_world.x();
 88    final_pose.position.y = storage_pose.position.y + vec_world.y();
 89    final_pose.position.z = storage_pose.position.z + vec_world.z();
 90
 91    // 6. Definição da Orientação Final do Objeto
 92    // Mantemos o objeto "em pé" (Roll/Pitch = 0), mas alinhamos o Yaw com a caixa.
 93    double r_temp, p_temp, yaw_storage;
 94    m_storage.getRPY(r_temp, p_temp, yaw_storage);
 95
 96    tf2::Quaternion q_final;
 97    q_final.setRPY(0.0, 0.0, yaw_storage); 
 98    q_final.normalize();
 99    final_pose.orientation = tf2::toMsg(q_final);
100    
101    // 7. Cálculo dos Próximos Índices (Lógica de Incremento)
102    // Preenche: Eixo X -> Depois Eixo Y -> Depois Eixo Z (Camadas)
103    int next_x = idx_x + 1;
104    int next_y = idx_y;
105    int next_z = idx_z;
106
107    // Se acabou a linha (X), vai para a próxima coluna (Y) e reseta X
108    if (next_x >= max_idx_x) 
109    {
110        next_x = 0;
111        next_y++;
112
113        // Se acabou a camada (Y), vai para cima (Z) e reseta Y
114        if (next_y >= max_idx_y)
115        {
116            next_y = 0;
117            next_z++;
118        }
119    }
120
121    std::vector<int> next_indexes = {next_x, next_y, next_z};
122
123    RCLCPP_INFO(rclcpp::get_logger("organize_node"), 
124        "Objeto posicionado em [%d, %d, %d]. Próxima vaga: [%d, %d, %d]", 
125        idx_x, idx_y, idx_z, next_x, next_y, next_z);
126
127    return std::make_pair(final_pose, next_indexes);
128}

Matemática de Transformação

Para garantir que o objeto seja colocado corretamente mesmo se a caixa estiver torta, utilizamos matrizes de rotação.

Seja \(P_{center}\) a pose da caixa e \(v_{rel}\) o vetor calculado na grade:

\[P_{final} = P_{center} + (R_{box} \times v_{rel})\]

Onde \(R_{box}\) é a matriz de rotação 3x3 derivada do quaternião da caixa. A orientação final do objeto é ajustada para manter o Pitch e Roll zerados (objeto em pé), mas herdando o Yaw da caixa para ficar alinhado.
